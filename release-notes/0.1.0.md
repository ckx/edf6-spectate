# EDF6 Spectate 0.1.0 experimental

**Known crash: do not use this version.** The first live attempt crashed when
entering spectate. Version 0.1.1 corrects the camera-ownership error and needs a
fresh online check:

https://github.com/ckx/edf6-spectate/releases/tag/v0.1.1

First packaged prototype. **Online behavior is untested.** Automated tests under
Wine passed with the supported game DLL; they do not establish live behavior.

When you go down online, the camera automatically follows a living teammate.
It switches if they go down or leave and returns when you revive or everyone is
down. There is no manual switching button yet. Your HUD stays unchanged, and other
players do not need the mod. Offline and split screen are left alone.

## Install

Close EDF6 and back up your saves. Download `EDF6Spectate-0.1.0.zip` below and
extract the whole archive to a separate folder. The GitHub source archives are
for developers and contain no plugin DLL.

- Windows: double-click `INSTALL.bat`. It finds the Steam installation or asks
  for its location.
- Linux / Proton: run `bash install.sh`. Add `WINEDLLOVERRIDES="winmm=n,b"` to the
  Steam launch command, keeping existing overrides and options. If the field was
  empty, use `WINEDLLOVERRIDES="winmm=n,b" %command%`.

The package includes EDFModLoader for a fresh installation. Installers preserve
an existing loader, other plugins and settings. EDF6Coop is not required.
Supports the Steam EDF.dll from the January 2025 update. Other or modified builds
are refused without patching.

Uninstall with `UNINSTALL.bat` or `bash install.sh --uninstall` with the game
closed. This removes only the spectator DLL.

## First online check

Check `Mods/Plugins/EDF6Spectate.log` for `Installed:`, then try going down,
watching a teammate move, and getting revived. Camera creation and handover,
teammate disconnects, mission transitions and compatibility with other mods still
need live verification. Keep the log if something fails.
