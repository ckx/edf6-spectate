# EDF6 Spectate 0.2.0 experimental

Adds the spectated teammate's native combat HUD to newly created spectator
cameras. The game builds the health, weapons, ammo, class gauges, radar and
crosshair for that player. Returning to your own camera restores its original HUD.

The user confirmed that camera following worked with 0.1.1. **The new HUD path
still needs an online check**, especially remote ammo, reloads and class gauges.
Values come from the game's local copy of the teammate; this mod sends no extra
network messages. Manual teammate switching is still not implemented.

Close EDF6, back up your saves, and extract `EDF6Spectate-0.2.0.zip` to a separate
folder. Windows: run `INSTALL.bat`. Linux: run `bash install.sh` and keep the Steam
launch override `WINEDLLOVERRIDES="winmm=n,b"` alongside existing options.
Existing loaders and other mods are preserved. Other players do not need the mod.

Try going down, watching the teammate fire and reload, and getting revived.
Check that your own health, weapon display and aiming return correctly. Retain
`Mods/Plugins/EDF6Spectate.log` and any crash log if something fails.
