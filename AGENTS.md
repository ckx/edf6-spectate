# Working instructions

This repository is retired. The spectator camera moved into EDF6Coop 3.1.0 on
2026-10-22 (user decision: one install, on by default, under EDF6Coop's terms).

Do all spectator camera work in the sibling `edf-coop-stable` repository
(`game/spectate.*`, `docs/spectate/`) under its AGENTS.md. Do not build, release or
change code here. Only the README pointer and these instructions may change.

Keep game data, binaries, saves, logs and temporary output out of Git. `local/`
holds the machine-specific evidence the research notes cite; keep it.

Commits use a lowercase imperative subject, 50 to 70 characters, with no prefix or
trailing period, and no AI attribution, co-author trailers or session links.
