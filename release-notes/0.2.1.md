# EDF6 Spectate 0.2.1 experimental

Removes the combat HUD attachment introduced in 0.2.0, which crashed when entering
spectate. Native damage, radar and weapon HUD code reads local-player settings
using an invalid index for a remote teammate. Stopping the plugin after a setup
fault cannot undo the HUD objects already registered with the game.

Spectating is camera-only again, using the same runtime path as 0.1.1, which the
user confirmed worked online. Full combat HUD support remains planned. This build
has been cross-compiled and packaged; it has not had a new online play check.
No CI or additional tests were added or run.

Close EDF6, back up saves, extract the ZIP to a separate folder, then run
`INSTALL.bat` on Windows or `bash install.sh` on Linux. Existing loaders, other
mods and launch settings are preserved. Replace 0.2.0 before playing again.

Check going down, following a teammate and returning to your own camera on
revival. Retain `Mods/Plugins/EDF6Spectate.log` and any crash log if it fails.
