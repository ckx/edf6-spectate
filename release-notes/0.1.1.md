# EDF6 Spectate 0.1.1 experimental

Corrects the camera-ownership bug found after 0.1.0 crashed on its first online
spectate attempt. **A successful online retry is still pending.**

The game's camera factory returns a weak reference. Version 0.1.0 released it as
a strong reference, which could destroy the queued camera before activation.
Version 0.1.1 releases the weak reference as the game's own caller does.

Close EDF6, back up your saves, and extract `EDF6Spectate-0.1.1.zip` to a separate
folder. On Windows, run `INSTALL.bat`. On Linux, run `bash install.sh` and keep the
Steam launch override `WINEDLLOVERRIDES="winmm=n,b"` alongside existing options.
The installer preserves existing loaders and other mods.

Following is automatic when downed online; there is no manual switching button.
Revival, teammate disconnects and mission transitions still need live checks.
If the game closes again, keep `Mods/Plugins/EDF6Spectate.log` and any crash log.
